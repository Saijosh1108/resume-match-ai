# ResumeMatch AI

An AI-powered resume analysis tool that compares a PDF resume with a job description using semantic similarity and skill coverage.

## Features

- Extracts text from uploaded PDF resumes with PyMuPDF.
- Compares resume and job-description meaning with the `all-MiniLM-L6-v2` Sentence Transformer.
- Detects and normalizes skills using a maintainable skill-alias dictionary.
- Reports matched and missing recognized skills.
- Calculates an experimental overall score from semantic similarity and recognized skill coverage.
- Generates rule-based resume improvement suggestions.
- Provides a Streamlit interface for interactive analysis.

> **Important:** Scores are experimental comparison signals, not predictions of hiring outcomes. Skill coverage includes only terms recognized by the current skill dictionary. Scanned PDFs without an OCR text layer are not currently supported.

## Run locally

Python 3.10 or newer is recommended.

1. Clone the repository:

   ```bash
   git clone https://github.com/Saijosh1108/resume-match-ai.git
   cd resume-match-ai
   ```

2. Create and activate a virtual environment:

   **Windows PowerShell**
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

   **macOS / Linux**
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Start the app:

   ```bash
   streamlit run app.py
   ```

The first semantic comparison downloads the Sentence Transformer model, so the first analysis may take longer. Later analyses reuse the model in the running process.

## Run tests

Install the test dependencies:

```bash
python -m pip install pytest pymupdf scikit-learn numpy
```

Run the test suite:

```bash
python -m pytest -q
```

GitHub Actions runs the tests automatically on pushes and pull requests targeting `main`.

## How the score works

- **Semantic similarity:** cosine similarity between the resume and job-description embeddings, displayed on a 0–100 scale.
- **Recognized skill coverage:** matched skills divided by the number of distinct skills detected in the job description.
- **Overall match score:** the equal-weight average of semantic similarity and recognized skill coverage, when at least one job-description skill is recognized.

This is a transparent, experimental heuristic. It does not assess seniority, quality of evidence, years of experience, or hiring likelihood.

## Current limitations

- Text extraction requires a text-based PDF; OCR for scanned resumes is not included.
- Skill extraction uses a dictionary and may miss synonyms or domain-specific requirements.
- Recommendations are rule-based rather than generated by a language model.
- The embedding model is downloaded at runtime on first use.
